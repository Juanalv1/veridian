1 Pon la clave en el entorno de tu app, nunca en el código 
VERIDIAN_API_KEY={{ key or 'vrd_...' }}
2 Instala el SDK 
$ pip install veridian-sdk
3 Agrega el middleware (FastAPI, Starlette o cualquier app ASGI) 
from fastapi import FastAPI
from veridian_sdk import VeridianMiddleware

app = FastAPI()

app.add_middleware(
    VeridianMiddleware,
    # Id de tu usuario, o None si nadie inició sesión
    user=lambda request: request.state.user.id,
    # Proxies tuyos delante de la app (0 si no hay)
    trusted_proxies=0,
)

La sesión se detecta sola y Veridian solo recibe un hash, nunca el valor. Si Veridian no responde, tu app sigue funcionando: deja pasar todas las peticiones.

trusted_proxies es cuántos proxies tuyos hay delante de la app (un balanceador, Render, Heroku: 1). Con 0 usa la IP de la conexión e ignora X-Forwarded-For, que cualquiera puede escribir.

Para comprobar la conexión, entra a tu app con un usuario: en unos segundos el acceso aparece en Actividad y el panel marca Conectado.

2 Instala el SDK 
$ npm install veridian-sdk
3 Agrega el middleware (Express) 
import express from 'express';
import { veridian } from 'veridian-sdk';

const app = express();

app.use(
  veridian({
    // Id de tu usuario, o null si nadie inició sesión
    user: (req) => req.user.id,
    // Proxies tuyos delante de la app (0 si no hay)
    trustedProxies: 0,
  }),
);

// ...aquí van tus rutas...

app.listen(3000);

La sesión se detecta sola y Veridian solo recibe un hash, nunca el valor. Si Veridian no responde, tu app sigue funcionando: deja pasar todas las peticiones.

Registra Veridian después del middleware que identifica a tu usuario (Passport, express-session) y antes de tus rutas. trustedProxies es cuántos proxies tuyos hay delante de la app (un balanceador, Render, Heroku: 1); con 0 se ignora X-Forwarded-For, que cualquiera puede escribir.

Para comprobar la conexión, entra a tu app con un usuario: en unos segundos el acceso aparece en Actividad y el panel marca Conectado. ¿Usas Next.js? Mira el README de veridian-sdk/next en npm.
