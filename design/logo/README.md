# Logo

"Huella": three concentric arches, like the ridges of a fingerprint. Behavior
identifies the owner the way a fingerprint does; the middle ridge is broken where
someone else got in.

Replaced the earlier mark (three nested V strokes) because it read as the Vue.js logo:
same nested-V shape in a very similar green.

| File | Use |
|---|---|
| `mark.svg` | Mark on dark backgrounds (`viridian` #4cc29a) |
| `mark-light.svg` | Mark on light backgrounds (`viridian` light #1e7a5e) |
| `icon.svg` | App icon, 32 px and up (two arches on `ground`, the inner one broken) |
| `favicon.svg` | Browser tab, 16 px (outer and inner arches, unbroken: the gap does not survive at that size) |

- Lockup: mark at the cap height of the wordmark, gap 0.3× the mark, wordmark "Veridian" in Archivo 800, color `ink`.
- One color only. Never add a second color to the mark.
