# Logo

"Huella": three nested V strokes that fade inward. Behavior identifies the owner,
the way a fingerprint does; the V is for Veridian and *verificar*.

| File | Use |
|---|---|
| `mark.svg` | Mark on dark backgrounds (`viridian` #4cc29a) |
| `mark-light.svg` | Mark on light backgrounds (`viridian` light #1e7a5e) |
| `icon.svg` | App icon, 32 px and up (two strokes on `ground`) |
| `favicon.svg` | Browser tab, 16 px (one stroke: the inner ones do not survive at that size) |

- Lockup: mark at the cap height of the wordmark, gap 0.3× the mark, wordmark "Veridian" in Archivo 800, color `ink`.
- One color only. Never add a second color to the mark.
